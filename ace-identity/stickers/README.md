# Buddy sticker pack (ACE)

16 stickers: hi!, yay, i'm listening, hmm..., on it, can i?, oops, brb, love it, wow, nooo, gotcha, WHAT, sus..., LMAO, grr.

| Folder | For |
|---|---|
| `png/` | 512×512 PNG, transparent: Telegram, Discord, iMessage, any sticker app |
| `webp/` | 512×512 WebP under 100 KB: WhatsApp |
| `tray-icon-96.png` | The pack icon (WhatsApp asks for a 96×96 tray icon) |

## WhatsApp (iPhone or Android)
WhatsApp doesn't let you add stickers directly from files, so use a free sticker app:
1. Install **Sticker Maker** (or "Sticker.ly").
2. Make a new pack called **Buddy**, author **NOVA OS**.
3. Add the images from `png/` (the backgrounds are already transparent, so skip any "cut out" step).
4. Pick `tray-icon-96.png` as the tray icon if the app asks.
5. Tap **Add to WhatsApp**.

## Telegram
1. Open **@Stickers** (the official bot) and send `/newpack`.
2. Name the pack **Buddy**, then send each PNG **as a file** (not as a photo) and an emoji for each.
3. Send `/publish`, then pick a short name like `nova_buddy`. You get a link to share: `t.me/addstickers/nova_buddy`.

## Discord
Server Settings → Stickers → Upload: use the PNGs (Discord wants files under 512 KB, and these are fine).
